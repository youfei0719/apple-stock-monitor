# 补货需求目录改造

用户要求：只收录新发售、热门且需要等补货的商品；普通长期现货不放进工具。曾经准备的全品类导入已停止，官网全量信息只用来识别入选商品，不能自动成为默认目录。

补货推荐清单为 iPhone 18 Pro / iPhone 18 Pro Max 的 11 个缺货配置：8 个 Pro Max、3 个 Pro。每个配置保存官网价格、颜色、容量、屏幕尺寸、SKU、A 型号、原始来源指纹，以及补货加入原因、核验门店与时间。

缺货证据来自 2026-10-12 的 Apple 南京东路 (R359) 库存响应。同系列 20 个已核验但样本门店有货的配置未进入推荐；1 个未取得独立核验结果的配置也不开放。该样本不是全国供货或连续缺货证明。后续应按用户目标城市与多日供应复核，再决定扩大或收缩清单。

其他品类不为凑全目录而开放。iPhone Duo 按用户要求作为下文所述的提前预约目标加入。旧目录的无效占位组合隐藏，已有监控任务保持可用。

前端从后端取得实际有推荐商品的品类，支持真实 SKU 配置筛选与明细核对。容量价格按配置显示最低价，“起”表示同容量其他配置有不同价格；跨品类或机型切换清空选择，忽略迟到的旧目录响应。创建任务保留完整配置描述，避免相同机型下不同配置丢失。

同步命令与规则见 `backend/app/api/routers/catalog_standard.md`；快照仅包含推荐条目，未加载全量 335 个候选商品。已于北京时间 2026-10-12 随 `bf82ffa` 部署至生产；见 [发布记录](release-2026-10-12.md)。

## 更新：支持 iPhone Duo 提前预约

根据用户补充，Duo 作为明确的新品预约目标加入，收录官方已公开的 8 个 SKU（夜空色、星光白色；256GB / 512GB / 1TB / 2TB），硬件型号 A3721。当前目录共 19 个配置：11 个带样本门店缺货证据的补货目标、8 个等待开售的预约目标。Duo 条目标记 `verification.status=scheduled` 与 `admission.reason=prelaunch_watch`，不宣称库存已验证。此前“未开放购买不加入”的规则对有官方配置与预购时间、用户明确要求提前预约的新品增加例外。

2026-10-12 核对官方购买页，预计 2026-10-16 20:00（北京时间）接受预购，2026-10-23 发售，并注明须获批准。只记录发售日期，不推断具体发售时刻。

登录后选择配置、门店和提醒方式，保存到现有任务表；匿名体验不能创建预约任务。开售前显示“等待开售”，不请求库存、不发到货通知、不计入长期缺货。到预购时间正常轮询所选门店，收到实际可自提结果才按即时/连续两次确认规则提醒，失败、未知、未开放自提或无货保持安静。链路沿用当前直营店自提库存接口，不检测快递购买或自动下单。

`TaskOut.launch`、`waiting_for_launch` 供前端展示；无需数据库迁移。本次生产已同步快照并重启 API 与独立引擎，公网已验证目录与新心跳。本地 API 设置 `ENGINE_ENABLED=false`，自动激活与通知分支使用隔离数据库和模拟 Apple 结果验证，没有实际发信或购买。
